- Outcome and acceptance criteria: a main menu shown before the watch (web, PWA, Tauri) with Continue, New game, Settings and Help, laid out like the approved reference (steel panel left, dusk scene right, sealed letter top right, tip ticker bottom). New game: optional u32 seed, a warning when a save exists. Continue: enabled only for a valid save, restored by replay(); shows seed and elapsed time only. Settings: master/Morse/hydrophone volume, sound on/off, reduce motion, interface (pixel-art or classic), stored under their own key. Help: how to play and the real key list. Out of scope: Quit (a browser cannot close its tab; the Tauri exit needs a capability), multiple save slots, i18n, remapping keys, menu music, the studio entry of the reference (not ours), copying any pixels or text from the reference.
- Material assumptions and risks: art is original TEMPORARY placeholder; audio is not audible-tested (no sound device); visual match is judged by me from the screenshot, not yet by the user; reload now opens the menu instead of auto-resuming (behaviour change; Continue restores).

## Architecture linkage

Page load -> main.ts decides: ?seed / ?play skip the menu, otherwise mountMenu() returns a choice -> Session.restore / fresh -> existing Store/Controller/scene. Settings: localStorage key uboat-radio.settings.v1 -> AudioEngine.setMix (master/morse/hydro buses) and html.reduce-motion + flags.reduceMotion. Menu button -> Controller.openMenu() -> save -> reload at the bare path.
